## 1. 최상위 원칙 — "디자인은 공유, 컴포넌트는 적응"

두 층을 분리한다. **디자인 시스템은 엄격히 공유하되, 콘텐츠 컴포넌트는 도구 상자로 본다.**

### (A) 공유 — 엄격 (이게 '같은 아카이브'로 읽히게 한다)

1. **디자인 발명 금지.** 저장소의 기존 공통 CSS(`assets/shared/...`)를 그대로 재사용. 시각 결과가 기존 시대 페이지와 구별되면 실패다.
2. **공유 대상 = 시각 언어.** CSS 토큰·색·타이포·평면 에디토리얼 룩·`§` 번호 체계·공통 헤더/푸터/내비·전체 질감. 페이지 '뼈대'(브레드크럼 → § 태그 → 제목 한/영 → 도입 → 통계 → 호흡 목차 → 본문 → Coda → 출처 메모 → 이전/다음)도 공유.
3. **브랜드·헤더·푸터·내비는 저장소 실제 파일을 따른다.** 브랜드 = *Archive for Som & Chan*. 한글 표기·내비 라벨은 추측 금지.

### (B) 적응 — 유연 (콘텐츠가 다르면 컴포넌트도 다르다)

4. **콘텐츠 컴포넌트(이벤트 카드·인물 소개·학설 갈래·시뮬·평행 박스)는 '무조건 따를' 대상이 아니라 도구 상자다.** 맞으면 쓰고, 안 맞으면 바꾸고, 콘텐츠가 요구하면 새로 만든다. 단, 토큰(색·타이포·여백·테두리)은 (A)를 따른다.
5. **컴포넌트 적합도는 챕터마다 다르다:**
   - **인간사 챕터(5~8부)** — 자연과학사 원래 컴포넌트가 잘 맞는다. 날짜형 이벤트 카드(흑사병 1347, 로스 1897…)·생몰년 인물 소개를 그대로 활용.
   - **심층시간 챕터(프롤로그~4부)** — "약 3억 년 전"이라 날짜·생몰년이 없다. 억지로 끼우지 말고 적응:
     - 생몰년 인물 카드 → **종(種) 카드**(학명·시대·크기·특징)
     - 날짜·장소 이벤트 카드 → **장면/증거 카드**(지질 사건·결정적 화석; 인간의 발견 사건일 때만 날짜 표기)
     - **자연과학사엔 없는 새 컴포넌트 허용**: 생활사(변태) 도식, 심층시간 스케일 장치, 해부 비교, 생태 네트워크 시뮬 등.
6. **이전 v1 샘플(`자연사_곤충_1부_석탄기_샘플.html`)은 폐기.** 디자인 표준은 ②다 — 단, ②의 컴포넌트도 (B)에 따라 챕터별로 적응한다.

## 5. 시대 페이지 구조

### 고정 뼈대 (모든 챕터 동일 — §1-A 공유)
1. 브레드크럼 `곤충의 역사 / § V 0N 〈시대명〉`
2. § 태그 `§ V · 0N`
3. 제목(한/영) + 부제(요약·시간 범위)
4. 문학적 도입문(*이탤릭* 강조)
5. 통계 4개(시간 범위 / 핵심 등장 / 인터랙티브 / 결정적 수치)
6. "이 시대를 N호흡으로" 챕터 목차(앵커)
7. §I 시기 도식(SVG)
8. 제1장 ~ 제N장 서사 (문학적 prose) + 마지막 장 = Coda
9. 출처 메모 §Citations + `/research/insects.html` 링크
10. 이전/다음 시대 내비

### 본문에 끼우는 콘텐츠 블록 (도구 상자 — §1-B 적응)
챕터 성격에 맞게 골라 쓰고, 안 맞으면 바꾸거나 새로 만든다. 디자인 토큰만 (A)를 따른다.

- **인물 소개 카드** `*한글명 원어명 (생몰년)*` — *발견한 과학자*에게(브롱니아르·다윈·파브르·윌슨·로스 등).
- **종(種) 카드** — *3억 년 전 생물*에게. 생몰년 대신 `학명 · 시대 · 크기 · 특징`.
- **장면/증거 카드** — 심층시간 챕터. 날짜·장소 대신 '결정적 화석·지질 사건'. (인간의 발견 사건일 때만 날짜형 이벤트 카드 사용.)
- **시뮬 블록**(시뮬 N + 한/영 소제목 + 실제 인터랙티브 + 단순화 명시).
- **학설 갈래 박스**(속설/학계/이 자료의 입장 3단) — Coda에.
- **평행 박스** "같은 시대, 한반도에서는 / Meanwhile in Korea" — 진짜 연결이 있을 때만.
- **새 컴포넌트 허용**(자연과학사에 없어도): 생활사(변태) 도식, 심층시간 스케일 장치, 해부 비교, 생태 네트워크.

> 즉 **자연과학사의 컴포넌트를 무조건 따르지 말 것.** 인간사 챕터(5~8부)는 원래 컴포넌트가 잘 맞고, 심층시간 챕터(프롤로그~4부)는 위 적응형을 우선한다.

**분량·밀도 목표:** 자연과학사 시대 페이지급 — 서사 챕터 4~6, 이벤트 카드 6~10, SVG 도식 2~4, 시뮬 2~4. ("내용이 짧다" 문제가 재발하지 않도록 이 밀도를 지킬 것.)

## 6. 톤 가이드 (자연과학사에서 추출)

- **인물·생물 중심 서사.** 사실 나열이 아니라 '누가, 언제, 무엇을 깨달았는가'. 곤충 자체도 등장인물이지만, **그것을 밝혀낸 과학자들의 인간 드라마**를 적극 활용.
- **이탤릭 강조**로 핵심 어구를 짚는다.
- **반복 모티프로 묶기.** (템플릿 예: "보이지 않는 공기가 그들을 키웠고, 거두었다.") 컬렉션 큰 모티프 = '작아서 이긴 자들'.
- **불확실성에 정직.** "추정", "전승", "학계 논쟁 중"을 숨기지 않는다.
- **위인전·과장 금지.** "위대한", "천재" 자제. 실패·집착·시대적 한계를 함께.
- **출처를 본문에 녹인다.** 이벤트 카드 끝에 짧은 출처 태그.
- **중·고생 어휘.** 용어집 hover, 한자어·학명·외국어 원어 병기.

## 7. 인터랙티브 시뮬 (시대당 2~4)

본문 결정적 순간에 삽입. 모두 "교육용 단순화 모형" 명시. (1부 템플릿에 산소→크기 슬라이더, 곤충↔다지류 토글이 작동 예시로 구현됨.)

- 프롤로그: 절지동물 분류 맞히기 · 탈피
- 1부: ✅산소→크기 슬라이더 · ✅곤충 vs 다지류 토글 (완성)
- 2부: 멸종 전후 다양성 막대 · 멸종 요인 토글
- 3부: 꽃–입틀 길이 매칭 · 완전/불완전 변태 한살이 · 호박 형성
- 4부: 군체 분업·페로몬 길찾기 · 진사회성 가계도
- 5부: 누에 한살이·실 길이 · 코치닐 색 추출
- 6부: 매개체 전파 모델 · 메뚜기 군집상 전환 · 흑사병 확산
- 7부: 수분 네트워크 붕괴 · 먹이그물 · 분해 속도

- 발견한 사람: *찰스 다윈 Charles Darwin* — 마다가스카르 별난초로 긴 입틀 나방 예언(사후 확인) ★이벤트 카드
- 이벤트 카드: 다윈 난초 예언(1862)·사후 확인 / 미얀마 호박(~9,900만 년) 곤충
- 시뮬: 꽃–입틀 매칭 · 변태 한살이 · 호박 형성
- 학설 갈래: 속씨식물 급팽창 시점(다윈의 '지긋지긋한 수수께끼')·벌 기원
- 평행(선택): 한국 백악기 곤충 화석(경상누층군 등) — **검색 후 사실일 때만**
- 용어: 속씨식물·공진화·수분·완전변태·호박

### 4부 — 작은 문명의 탄생 〈신생대 사회성〉
- 호흡: ① 빈자리 ② 진사회성이란 ③ 개미·흰개미(수렴) ④ 초개체 ⑤ Coda
- 발견한 사람: *파브르 Jean-Henri Fabre 1823–1915* · *카를 폰 프리슈 Karl von Frisch 1886–1982*(꿀벌 춤, 1973 노벨) · *에드워드 윌슨 E. O. Wilson 1929–2021*
- 이벤트 카드: 폰 프리슈의 8자 춤 해독 / 지구 개미 개체수 추정(수치 검색)
- 시뮬: 군체 분업·페로몬 · 진사회성 가계도
- 학설 갈래: 진사회성 진화(혈연선택 vs 집단선택)
- 용어: 진사회성·군체·분업·초개체

### 5부 — 인간을 만나다 〈실크·꿀·염료〉
- 호흡: ① 비단의 제국 ② 꿀과 밀랍 ③ 붉은 금 코치닐 ④ Coda
- 핵심: 누에 <em>Bombyx mori</em> · 코치닐 <em>Dactylopius coccus</em> · 락깍지벌레
- 이벤트 카드: 중국 양잠 기원(~5,000년 전) / 코치닐 식민지 무역 / 선사 채밀 암벽화(연대 검색)
- 시뮬: 누에 한살이·실 길이 · 코치닐 색 추출
- 평행: 동아시아 양잠·양봉(적극 활용) / 용어: 양잠·가축화·코치닐

### 6부 — 인간 역사를 뒤흔든 작은 존재들 〈질병·재해〉
- 호흡: ① 모기·말라리아 ② 벼룩·흑사병 ③ 이·전쟁(티푸스) ④ 메뚜기 떼 ⑤ Coda
- 발견한 사람: *로널드 로스 Ronald Ross 1857–1932*(모기-말라리아 매개, 1902 노벨) — 검증

- 학설 갈래: 흑사병 전파 경로 논쟁 / 톤: 사실 위주, 자극적 묘사 금지, 중학생 적합
- 용어: 매개체·말라리아·페스트·발진티푸스·사막메뚜기

### 7부 — 지구를 떠받치는 보이지 않는 일꾼들 〈생태계〉
- 호흡: ① 꽃가루를 나르는 자들 ② 분해·순환 ③ 먹이그물의 바닥 ④ 숫자의 제국 ⑤ Coda
- 발견한 사람: 의태 — *베이츠 H. W. Bates* · *뮐러 Fritz Müller*
- 이벤트 카드: 베이츠의 아마존 의태 관찰 / 수분 의존 작물 비율 연구
- 시뮬: 수분 네트워크 붕괴 · 먹이그물 · 분해 속도
- 학설 갈래: '작물 종류 ~3/4' vs '생산량 기준' 통계의 정확한 의미
- 용어: 수분·분해자·생태계 서비스·생물량

### 에필로그 — 사라지는 곤충, 우리의 미래 〈현재〉
- 호흡: ① 사라지는 숫자 ② 원인들 ③ 얼마나 확실한가(갈래) ④ Coda: 다음 한 줄은 우리가
- 이벤트 카드: 크레펠트 연구(2017, 비행곤충 생물량 27년간 70%대 감소) — 수치 검증
- 시뮬: 감소 그래프 시나리오(요인별)
- 학설 갈래: '곤충 종말' 사실인가 — 심각한 우려 vs 일반화 과장 비판. 입장 = 단정하지 않되 경시도 안 함
- 용어: 생물다양성·서식지 파괴·살충제

## 10. 작업 순서

1. 공통 내비에 **곤충의 역사** 추가 + §번호·`.collection-insect` 액센트 한 줄.
2. **1부**: 템플릿(②)을 `01-carboniferous.html`로 배치 → `<style>`을 저장소 실제 CSS로 교체 → 출처 web_search 검증. (구조·콘텐츠는 완성.)
3. `index.html` (통합 연표 + 9개 시대 카드 + 이 자료의 톤).
4. **프롤로그**를 템플릿 구조로 작성 → 사용자 검토.
5. 확정 후 2부 → 8부 순차. 각 시대: 서사 챕터 골격 → §1-B 도구 상자에서 챕터에 맞는 콘텐츠 블록(종 카드/장면·증거 카드/시뮬/학설 갈래 등) 선택 채움 → Coda. **장 단위로 저장.**
6. `/research/insects.html` 작성·연결.
7. 통합 검수: 반응형 · 용어집 hover · 내부 링크 · 모든 시뮬 작동 · 폰트.

## 11. 콘텐츠 작성 주의사항

- **디자인 토큰·뼈대는 기존 시대 페이지와 동일.** 단 콘텐츠 컴포넌트는 §1-B대로 챕터에 맞게 적응·교체·신설(무조건 복제 금지).
- 인물·학명·외국어 원어 병기. 사람=생몰년, 생물=학명·시대.
- 위인전·과장 금지. 불확실성·논쟁 그대로.
- 각 시대에 '발견한 사람'(또는 종 카드) + '학설 갈래' 포함.
- 시각화 = 직접 만든 SVG/시뮬만. 외부 사진·삽화·로고 금지(저작권). 시뮬은 단순화 모형 명시.
- 6부 등 민감 주제는 담담·정확·중학생 적합.
- 모든 사실 web_search 재검증 → `/research/insects.html` 기록.

## 13. 마지막 당부

이것은 **Archive for Som & Chan**의 다섯 번째 권이다. 자연과학사가 "인간이 자연을 어떻게 알아왔는지"의 기록이라면, 곤충의 역사는 *가장 작고 하찮아 보이는 존재가 어떻게 이 행성을 가장 먼저, 가장 널리 정복했는지* — 그리고 그것을 밝혀낸 사람들 — 의 기록이다.

문체는 자연과학사와 한 형제처럼 읽혀야 한다. 인물의 삶을 통해, 결정적 장면을 통해, 그러나 정밀한 사실 위에서. 백과사전이 아니라 **호기심의 지도**로. 화려함보다 신뢰성, 인상보다 정확성, 그러나 살아있는 이야기로.
