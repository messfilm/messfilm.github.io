# § VI 곤충 전쟁 — 한국어 말투/어투 폴리시 가이드

3차 검수 중 사용자 피드백: "초반에 이미 한국어 어투가 어색한 문장들이 보여, 특히 '말투' 부분, 신경써서 재검수해줘 전반적으로"

## 적용 원칙

**기존 산문체는 유지** (이야기 톤은 작가 스타일). 다듬는 것은 **대사·호칭·자연스럽지 않은 어순/직역체**에 집중.

---

## 1. 호격 (vocative) 통일

부를 때 (호격) vs 지칭할 때 (주격)을 정확히 구분.

| 상황 | 잘못 | 바로잡기 |
|------|------|----------|
| 부를 때 | "안녕, 솜이." | "안녕, 솜아." |
| 부를 때 | "이게 뭐야, 솜이?" | "이게 뭐야, 솜아?" |
| 부를 때 | "찬이, 이리 와" | "찬아, 이리 와" |
| 지칭 (주격) | "솜이가 그렸어" | OK 그대로 |
| 지칭 (목적격) | "솜이를 봤어" | OK 그대로 |

예외: 솜이 자기 자신을 가리키며 말할 때 "솜이가" 식으로 어린이가 3인칭화하는 경우는 캐릭터 톤으로 유지.

---

## 2. 어른→아이 톤 통일

**원칙: 한 캐릭터 안에서 한 챕터 동안 톤이 흔들리지 않게.**

### 정연우 (50세 박사, 아이들과 친밀해진 후)
- 친한 반말 톤: "할게", "했어", "그래", "맞아"
- 격식 평어 ("한다", "했다", "갈 것이다") 와 **혼용 금지**
- 예외: 학자적 사실 설명 시 평어 가능. 단, 같은 문단 안에서 톤 일관성 유지.

### 외할아버지 (72세, 임종 직전)
- 격식 평어 OK: "준다", "가라", "알았지"
- 노인 특유의 잔잔한 음. "거다"는 OK.

### 아미라/카밀 (외국인, 통역체)
- 격식 존대 또는 격식 평어로 일관. 어색한 한국어가 아니라 **명료한 한국어**로 옮긴다 (통역체).

### 라이언 카터 (한국계, 한국어 가능)
- 친밀 반말 가능. 단, 자연스러운 한국어가 어색해지는 자리에만 살짝 영어 단어 섞기 OK.

---

## 3. 직역체 명사구 교정

| 잘못 (직역) | 자연스러운 한국어 |
|-------------|-------------------|
| "다른 무엇이에요" | "뭔가 다른 거예요" / "다른 거예요" |
| "그 날 밤의 그 보라색" | "그날 밤 그 보라색" |
| "벌통의 일벌" | "벌통의 일벌" (OK) 또는 "벌통에 사는 일벌" |
| "한 마리 벌이" | "벌 한 마리가" |
| "한 책이 나왔다" | "책이 한 권 나왔다" |
| "한 작은 사람" | "작은 사람" / "키 작은 사람" |
| "그것은 있는 거예요" | "그건 있는 거예요" |
| "안 맞잖아요" (13세 → 박사) | "안 맞는 거 같아요" (살짝 완화) |
| "너는 누구지?" | "누구지?" / "어떻게 왔니?" |

---

## 4. 끊김 과다 (em-dash 남용) 완화

영어식 punchy cut을 한국어 흐름으로 풀어주기. **단, 의도된 망설임·강조는 유지.**

### Before
> "박사님 발표 들었어요. 맨 뒤에 서서. 살충제 7가지가 동시에 듣지 않게 됐다는 거요."

### After
> "박사님 발표 들었어요, 맨 뒤에 서서. 살충제 7가지가 동시에 듣지 않게 됐다는 거 — 박사님은 진화로 설명하셨지만 진화 속도로는 안 맞는 거 같아요."

원칙: **마침표보다 쉼표·연결사가 자연스러우면 풀어준다.** 다만 너무 매끄럽게 풀어서 13세의 끊기는 말투가 사라지지 않도록.

---

## 5. "-시-" 과잉 / 부족 교정

### 어색한 자리
- 정연우가 자기 동기(찬 부모)에 대해 말할 때: "연구하시던" → "연구하던" (동기는 본인보다 높이지 않음)
- 라이언이 정연우에게: "정 박사가 했다" → "정 박사님이 하셨다" (한국에서 동료라도 박사 호칭은 "-님" + "-시-")

### 필요한 자리
- 외할머니 → 외할아버지 (배우자): "잡수셨어요?" 같은 자연스러운 -시-
- 어린이 → 어른: 항상 "-셨어요", "-세요"

---

## 6. 어미 톤 (옛스러움/현대) 균형

- 외할아버지의 "가지고 있을 거다" / "갈 거다" — 노인 톤으로 OK
- 정연우의 "있을 거다" — 학자 톤이지만 아이들에게는 "있을 거야" 가 더 자연스러움
- 13세 찬: "있는 거예요" / "그런 거예요" — OK
- 10세 솜: "보라색이 나요" / "제가 본 거예요" — OK, 짧고 정확

---

## 7. 인용 부호·문장 부호

- 큰따옴표 직접 인용 내부에서는 마침표 사용. 끝에 가까운 자리에 "—" 가 있으면 끊김 검토.
- 인용문이 끝나고 "그가 말했다" 가 붙는 자리: "X." 그가 말했다. (마침표 안)
  - 한국어 관습으로 OK, 다만 "X," 그가 말했다 도 허용.

---

## 8. 캐릭터별 핵심 입버릇 (시트 기반, 챕터 안 최소 1회 유지)

- **솜**: "제가 본 건 진짜예요"
- **인성**: "솜아 오빠랑 가자"
- **아미라**: "내 가족은 박멸로 살아오지 않았다."
- **외할아버지** (회상): "곤충은 말을 걸어 올 것이다. 우리는 들을 준비를 해야 한다."

위 입버릇은 챕터별로 한 번 이상 등장해야 하며, 다른 캐릭터가 인용하는 경우도 정확히 옮긴다.

---

## 9. 작업 방식

각 챕터에서:
1. 본문 산문체는 **건드리지 않는다** (작가 스타일)
2. `<p>` 안의 큰따옴표 대사를 우선 점검
3. `<blockquote class="quote">` 인용도 점검
4. 호격, 직역체 명사구, 끊김 과다, 톤 혼용을 **Edit 도구로 정밀 교정**
5. 한 챕터당 평균 5-15 군데 정도의 교정 예상

---

## 10. 톤이 살짝 어색해도 유지할 자리

- 곤충 측 챕터의 추상 분자 어휘: "본능 사전에 항목이 추가되었다" → 의도된 알 수 없는 톤이므로 **유지**
- 외할아버지 노인 톤의 "거다" 어미 → **유지**
- 솜의 어린이 직선 화법 → **유지** (다만 자연스럽지 않은 직역체는 교정)

---

## 11. 검수 후 확인

각 챕터 폴리시 후:
- `data-page-id` 변경 없음 확인
- `chap-nav` 링크 변경 없음 확인
- `<blockquote class="quote">` 안의 핵심 인용 의미 보존 확인
- HTML 구조 보존 (열고 닫는 태그)
