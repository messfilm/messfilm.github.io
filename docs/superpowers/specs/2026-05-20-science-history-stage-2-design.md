# Science History — Stage 2 (Foundation + Sample Era) Design

**Date:** 2026-05-20
**Scope:** 자연과학사 기획서 + 본격 메인 + 표본 시대 1개 (03-과학혁명)
**Out of scope:** 나머지 5개 시대(01·02·04·05·06), 통합 검색, 모바일 햄버거

---

## 1. 목표

1. 자연과학사 컬렉션을 placeholder 상태에서 **항해 가능한 본격 메인**으로 전환.
2. 시대 페이지의 **표준 구조와 시각 어법**을 표본(03-과학혁명)으로 확정. 이후 5개 시대는 이 표본을 따른다.
3. 한국사 시대 페이지와 **시각·구조 일관성**을 유지하되, 자연과학사 고유의 가치(인터랙티브 시뮬레이션)를 더한다.

## 4. 기획서 (`science_history_dashboard_prompt.md`)

한국사 README·종교사 기획서 톤으로 자연과학사 프로젝트 자체를 정의:

- 누구를 위한 자료인가 (자녀, 호기심 있는 중고생, 일반인)
- 시대 구분 6개 (placeholder의 정의 그대로) + 각 시대 핵심 인물·발견 줄거리
- 콘텐츠 톤 — 서양 주류 + 동양·이슬람 기여 별도 서술
- 시각 어법 — 한지·잉크청 액센트, SVG·Canvas 인터랙티브
- 시대 페이지의 표준 구조 (Hero/시기 도식/인물 카드/사건 연표/인터랙티브/별도 박스/학설 갈래/출처)
- 학설·해석 갈래 처리 원칙 (양립 서술)
- 참고 출처 (MacTutor, Stanford Encyclopedia of Philosophy, NASA, Galileo Project 등)

분량: 한국사 README(~100줄) + 마스터 아키텍처 톤. 약 200~300줄.

## 6. 표본 시대 (`/science-history/eras/03-revolution.html`)

한국사 시대 페이지를 모델로. 한국사 04-goryeo (~990줄) 정도 분량.

### 6.1 구조

1. **Hero** — § III · 03 / 과학혁명 1500~1700 / 한 단락 도입 / 시기 통계(140~200년, 핵심 인물 8, 인터랙티브 3)
2. **§ I 시기 도식** — 1500 → 1700 가로 띠 SVG, 결정적 사건 7~10개 마커 (1543 De Revolutionibus & De Humani Corporis, 1572 Tycho 초신성, 1609 케플러 1·2법칙, 1610 갈릴레오 망원경 발견, 1620 베이컨, 1628 하비 혈액순환, 1665 후크 Micrographia, 1687 Principia)
3. **§ II 핵심 인물 카드** — 6~8명. 각 카드: 초상 자리(생략, 이름 타이포그래피)/생몰/주요 업적/시대적 의미
   - 코페르니쿠스 (1473–1543)
   - 베살리우스 (1514–1564)
   - 갈릴레오 (1564–1642)
   - 케플러 (1571–1630)
   - 데카르트 (1596–1650)
   - 하비 (1578–1657)
   - 보일 (1627–1691)
   - 뉴턴 (1643–1727)
4. **§ III 결정적 전환들** — 단락형 서술 4개
   - 천문 — 지구 중심에서 태양 중심으로
   - 운동 — 정성에서 정량 (갈릴레오·뉴턴)
   - 인체·생리 — 베살리우스·하비
   - 방법 — 베이컨·데카르트 (귀납과 의심)
5. **§ IV 인터랙티브 3개** — 각각 별도 카드:
   - § IV.1 — 태양 중심 vs 지구 중심 (모델 비교 토글)
   - § IV.2 — 케플러 제2법칙 (면적 속도 시각화)
   - § IV.3 — 뉴턴 만유인력 (거리에 따른 힘)
6. **§ V 동양·이슬람 기여 박스** — 같은 시기 동아시아·이슬람권 과학(서광계와 마테오 리치, 송응성 천공개물, 명청 천문, 이슬람권의 후기 천문 수학)
7. **§ VI 학설 갈래** — 단정하지 않고 양립
   - 코페르니쿠스 혁명의 사회적 충격 정도(과장 vs 학계 합의)
   - 뉴턴-라이프니츠 미적분 우선권
   - 갈릴레오 재판의 역사적 해석 (종교 vs 과학 단순화 비판)
8. **§ VII 출처 메모** — `/research/science.html`로 링크

### 6.2 시각

- 한국사 시대 페이지의 액센트(청자색)는 이 페이지에서 잉크청 `#2a5680`로 교체

- 인터랙티브 카드는 별도 컴포넌트 (200~280px 높이 영역)

## 7. 인터랙티브 시뮬레이션 사양

### 7.1 공통 규약

- 외부 라이브러리 없음. 순수 SVG·Canvas + 바닐라 JS.
- 각 시뮬은 자기 자신을 한 컨테이너 `<div class="sim" data-sim-id="...">`에 부착.
- 시뮬 컨테이너 안에 캔버스·SVG와 컨트롤(슬라이더·토글)이 함께.
- 컨트롤 폰트는 공통 변수(`--sans-ko`). 액센트는 페이지의 `--accent`.
- 접근성: 키보드 조작 가능. `aria-label` 부여. 시뮬 멈춤·재개 버튼.

### 7.2 sim-heliocentric.js — 태양 중심 vs 지구 중심

- 두 패널을 좌우 또는 토글로 표시
- 지구 중심: 지구 가운데, 태양·달·5행성이 epicycle을 그리며 도는 모델 (단순화)
- 태양 중심: 태양 가운데, 행성들이 원궤도로 도는 모델 (이심률 무시, 코페르니쿠스 원형 가정)
- 컨트롤: "모델 전환" 토글, "재생/멈춤", "속도" 슬라이더
- 의도: 행성 역행 운동이 태양 중심 모델에서 자연스럽게 설명됨을 시각화

### 7.3 sim-kepler.js — 케플러 제2법칙

- 단일 타원 궤도 위 행성이 도는 SVG 애니메이션
- 행성-태양 잇는 선이 일정 시간 동안 스치는 부채꼴을 잔상으로 표시
- 컨트롤: "재생/멈춤", "이심률" 슬라이더(0.0~0.8)
- 의도: 행성이 태양에 가까울수록 빠르게, 멀어지면 느리게 움직임을 보여줌

### 7.4 sim-newton-gravity.js — 만유인력

- 가운데 큰 태양(또는 행성), 우측에 작은 위성
- 위성 거리 슬라이더 (1.0~5.0 단위)
- 거리에 따른 힘 값이 `F ∝ 1/r²` 식으로 표시
- 두 화살표: 위성에 작용하는 힘 벡터, 위성의 속도 벡터
- 애니메이션: 실제 궤도가 시작 속도와 거리에 따라 원/타원/포물 도출
- 컨트롤: "거리" 슬라이더, "초기 속도" 슬라이더, "리셋"

### 7.5 파일 구조

각 파일은 IIFE로 자기 등록:
```js
(function () {
  function init(container) { /* ... */ }
  document.querySelectorAll('[data-sim-id$=".sim.kepler"]').forEach(init);
})();
```

## 11. 위험·트레이드오프

- **시뮬 정확도 vs 단순화**: 케플러 시뮬에서 실제 타원 궤도 수학을 정확히 풀지 않고 근사(이심률 매개변수로 SVG path 그리기) → 학습 의도엔 충분, 학술 정밀도 X. 페이지에 "단순화 모형" 명시.
- **인터랙티브 + 인쇄/저속 환경**: requestAnimationFrame 사용. 모바일 절전 시 멈춤 가능. 사용자 동작 후 자동 일시정지 옵션.
- **나머지 5개 시대 미완성으로 인한 불완전감**: 마스터 아키텍처의 가치 "출처 추적 가능 + 점진 갱신"으로 정당화. updates.json에 작업 일정 명시.
