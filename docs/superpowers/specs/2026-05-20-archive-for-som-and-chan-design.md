# Archive for Som & Chan — 리브랜딩 & 헤더 통일

**Date:** 2026-05-20
**Status:** 사용자 승인 완료, 적용 단계

## 배경

기존 "아들을 위한 아카이브 — Archive for My Son"은 첫째 아들 한 명을 전제로 한 브랜드였다.
이제 두 자녀(솜, 찬)를 위한 아카이브로 확장하고, 동시에 헤더 구조도 단순화하여 유지보수성을 개선한다.

## 결정 사항

### 1. 브랜드 명명

- **타이틀**: `Archive for Som & Chan` (영문만)
- **타이포 위계**: "Archive for"는 작은 키커 (12px, 자간 0.18em, 대문자), `Som & Chan`은 큼지막한 사인 (30px, Cormorant Garamond Italic, & 기호는 금니색)
- 헤더에서 한글 명칭은 사용하지 않음 (대문 hero에서만 보조적으로 등장)

### 2. 로고 (두 얼굴 메달리온)

- **선택된 시안**: Variant A — 두 메달리온이 살짝 겹치며 각자 금니 테두리 유지
- 솜은 왼쪽, 찬은 오른쪽
- 한글 이름표(솜·찬) 없음; 영문(Som / Chan)만 대문 hero의 메달리온 아래에 명패로 표기
- **SVG 손코딩**, 외부 이미지 의존 없음

### 3. 캐리커처 스타일 (v6 확정)

- **공통**: 한지 배경(#faf6eb), 먹선(#1f1a14), 금니 테두리(#a37e2c)
- **솜**: 둥근 얼굴 + 납작한 두피 dome + 가운데 가르마 일자 앞머리 + 옆머리 어깨까지 + 크고 동그란 눈 + 사과볼 핑크 + 한 줄 곡선 미소 + 청·흰 줄무늬 폴로 + 검은 앞치마
- **찬**: 둥근 얼굴 + 삐친 머리 + 둥근 안경 + 한 줄 미소 + 드로우스트링 재킷
- 추후 더 닮게 다듬을 여지를 남김 (현재는 "상징적 초상" 단계)

### 4. 전역 헤더 구조

- 좌측: 두 메달리온 로고 + 브랜드 텍스트 → 전체 클릭 시 대문(`/`)으로
- 우측: **챕터 이동 nav 링크 모두 제거** (`종교사 | 한국사 | 자연과학사 | 연구`)
  - 이유: 유지보수 — 컬렉션 추가/이름 변경 시 nav 코드를 만지지 않아도 됨
  - 챕터 간 이동은 대문 카드 그리드에서만
- 우측에 작은 "↑ 대문으로" hint는 유지 (현재 위치를 알리는 의미)

### 5. 대문(landing) hero 영역

- 기존 `<h1>아들을 위한 아카이브 ...</h1>` 제거
- 두 메달리온을 큼직하게 (240×280px) 살짝 겹쳐서 중앙 배치
- 그 아래 `Archive for / Som & Chan` 큼직한 사인
- "est. 2026 · Seoul" 키커는 유지
- lead 문장: "한 아버지가 자녀에게..." → "한 아버지가 두 아이에게..." (복수형)

### 6. 적용 대상

| 파일 | 변경 내용 |
|------|----------|
| `assets/shared/nav.js` | 브랜드 SVG + 텍스트 교체, nav 링크 배열 제거 |
| `assets/shared/styles-base.css` | 헤더 CSS 재설계 (.brand-stack, .brand-text 등), nav 스타일 제거 |
| `assets/shared/footer.js` | © 카피 문구 영문화 |
| `assets/shared/research-loader.js` | 헤더 주석만 |
| `index.html` | title, meta, hero 섹션 재작도 |
| `research/*.html`, `science-history/**/*.html` (그 외 sub-page) | `<title>` 태그의 "아들을 위한 아카이브" → "Archive for Som & Chan" |

### 7. 명시적 비범위

- 대문 카드 그리드, 미니 timeline SVG, "읽는 법" 가이드 섹션은 변경하지 않음
- 각 컬렉션 내부(eras 페이지)는 헤더만 자동 변경됨 (nav.js 주입)
- 캐리커처 추가 다듬기는 별도 작업
